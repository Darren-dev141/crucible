- Read each map of a material with its own UV set in the WebGL and WebGPU path tracers: the GPU triangle record gains a texel for `TEXCOORD_1` (ten texels, 160 bytes a triangle; the native tracer keeps its nine-texel record) and the material record a per-map bit mask, so a floor with a `TEXCOORD_0` base colour and a `TEXCOORD_1` emissive map matches the CPU tracer.
