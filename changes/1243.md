- The path tracer reads a map on `TEXCOORD_1` with the second UV set: the CPU tracer samples each map with the set its `uvChannel` names (a glTF base color on `TEXCOORD_1` beside a `TEXCOORD_0` normal map no longer reads UV (0, 0)), and the WebGL and WebGPU tracers read the set of the material's base color for all its maps. A part with a map on `uvChannel` 1 but no `geometry.lightUvs` is refused with an error that says what to set, on every tracer. The native Cook kernel reads each map with its own set as well, so a `TEXCOORD_1` map no longer samples UV (0, 0) there (#1243).
