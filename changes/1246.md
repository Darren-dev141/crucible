- A failed job release, status write or browser launch no longer breaks the MCP runtime: a retry finishes the release (a file held open by another program no longer takes the store down, and a folder that lost its owner file is healed), `close` always gives back the store lock and ends a pending `scene_ask_user`, kept exports are counted across runs, and a recipe over the 64 MiB asset limit (grid and look files included) is refused before any file is read (#1246).
